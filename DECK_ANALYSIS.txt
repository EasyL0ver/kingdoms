2. TRIGGER DISTRIBUTION (Event Response Types)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

COMPLETE TRIGGER INVENTORY:

on_order (30 cards) — *DOMINANT* — Player orders the card voluntarily
  Actions that affect yourself, opponents, or zones
  Examples: Mine (draws coin), Plough (orders wheat), Crags (scouts claw)
  
on_dawn (16 cards) — Automatic at start of turn in your domain
  One-shot effects or conditional placements
  Examples: Harvest (triggers harvest event), Incite (move mobs), Regrowth
  (recover pastures), Famine (force opponent discard)
  
on_brawl (9 cards) — Triggered when Brawl event hits your domain
  Defense mechanics or counter-attacks
  Examples: Raid (give/discard to attacker), Crags (defense), Militia (cancel)
  
on_rite (5 cards) — Triggered when Rite event hits your domain
  Secondary triggered effects
  Examples: Worship of the Hunt (triggers feast), Worship of War (brawl)
  
on_harvest (4 cards) — Triggered when Harvest event hits your domain
  High-impact decisions
  Examples: Plough (feast or order wheat), Animal Husbandry (sacrifice pasture)
  
on_feast (3 cards) — Triggered when Feast event hits your domain
  Passive benefits or resource management
  Examples: Tavern (return discontent), Marauders (draw)
  
on_rumour (1 card) — Triggered when Rumour event (only from Coin Zone trade)
  Example: Village Gossip (peek/bury card)

└─ PATTERN: Order > Dawn > Brawl/Rite > Harvest/Feast >>> Rumour ─────────────┘

4. THE EVENT SYSTEM — Core Game Loop
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

GAME TURN STRUCTURE:
  1. DAWN PHASE (all on_dawn triggers fire in player's domain)
     └─ Cards with on_dawn execute one-shot effects
     └─ Example: Harvest triggers Harvest event → all Harvest responders fire
  
  2. ORDER PHASE (player chooses one action from valid_actions)
     └─ Order a domain card (if it has on_order)
     └─ Order discard card (if it has on_order)
     └─ Order from someone's Well (on_order with different active_player)
     └─ Order Presence (allows choice of Claw or Tree zone)
     └─ Pass (if no valid actions)
  
  3. ZONE ORDERING (if player orders a zone)
     ├─ Claw Zone: draw 2 cards
     ├─ Tree Zone: pick 1 from Season, refill to 4
     ├─ Wheat Zone: pick 1-3 from Fields, pay Claw tax (draw that many)
     └─ Coin Zone: buy 1 from Wares OR trade 1 domain card to Wares + draw Coin
                  (trade triggers Rumour event)

EVENT TYPES (5 main + 1 special):
  ├─ BRAWL (Combat event)
  │   Triggered by: Warband, Gathering, Gathering (2nd brawl), Racketeering,
  │                 Blood Feud retaliation, Worship of War, Uprising, Tyranny
  │   Responders: Raid, Scavenge, Eldership (cancel), Crags (defense),
  │               Rite of Passage (draw tree), Blood Feud (draw + move mobs + retaliate),
  │               Spoils of War (give trophy), Militia (cancel), Enforcers (arms race)
  │   Mechanics: 
  │     • Broadcast to target player's domain in play order
  │     • Cards decide: allow, cancel, or resolve with consequence
  │     • Some return spoils to attacker, others return to attacker
  │
  ├─ HARVEST (Agricultural event)
  │   Triggered by: Harvest card (on_dawn), Gathering choice, Plough option,
  │                 Worship of Fertility
  │   Responders: Solstice, Kinship, Plough, Animal Husbandry
  │   Side Effect: Wheat Zone refills Fields to 5
  │   Mechanics: High-impact decision point (draw vs place, sacrifice, etc.)
  │
  ├─ RITE (Spiritual event)
  │   Triggered by: Sky Dance (order), Blood Offering (order),
  │                 Gathering choice, Sacred Grove choice, Dusk Rite,
  │                 Worship of War (rite during brawl!)
  │   Responders: Worship of the Rain, Worship of Fertility, Worship of the Hunt,
  │               Worship of War, Worship of the Flame
  │   Mechanics: Spiritual cards respond in sequence; Worship of the Flame draws
  │              based on # of Spiritual responders
  │
  ├─ FEAST (Sustenance event)
  │   Triggered by: Granary (order), Plough (harvest choice), Animal Husbandry,
  │                 Poach (claw order), Marauders (brawl)
  │   Responders: Tavern (return discontent), Marauders (draw), Share the Spoils (draw)
  │   Mechanics: Low-impact compared to Harvest/Rite
  │
  ├─ RUMOUR (Information event)
  │   Triggered by: Coin Zone Trade action
  │   Responders: Village Gossip (peek top/bury)
  │   Mechanics: Only one card responds; very narrow event
  │
  └─ (Implicit) ZONE ORDERING (not an "event" but zone-specific on_order)
      Claw Zone, Tree Zone, Wheat Zone, Coin Zone have on_order methods

EVENT DEPTH LIMIT: 10 (prevents infinite loops)

5. GAME END CONDITIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

From state.py check_game_end():

┌─ THREE-ZONE DECKS (Pile + Face-up area must BOTH be empty) ──────────────────┐
TREE:   Pile empty AND Season empty → TREE DEPLETES
  Winner: Most Nature tags
  
WHEAT:  Pile empty AND Fields empty → WHEAT DEPLETES
  Winner: Most Amenity tags
  
COIN:   Pile empty AND Wares empty → COIN DEPLETES
  Winner: Most Amenity tags (note: shares win condition with WHEAT!)

└─ TWO-ZONE DECKS (Pile only) ──────────────────────────────────────────────────┘
CLAW:   Pile empty → CLAW DEPLETES
  Winner: Most Trophy tags
  
CANDLE: Pile empty → CANDLE DEPLETES
  Winner: ??? (No winning tag defined; would need to add "Flame" tag)

Win Conditions by Depletion:
  • tree depletes → race for NATURE tags
  • claw depletes → race for TROPHY tags
  • wheat depletes → race for AMENITY tags
  • coin depletes → race for AMENITY tags (same as wheat!)

┌─ PATTERN ─────────────────────────────────────────────────────────────────────┤
Each major deck defines a "race condition" — the piles are the deadline, but
the winning tag defines which cards matter. This creates incentive alignment:
  • Want Tree depleted? Build Nature.
  • Want Claw depleted? Build Trophy.
  • Want Wheat depleted? Build Amenity.

BUT: Coin and Wheat both race for AMENITY (potential design issue!)
AND: Candle has no winning condition tag (totally underbaked)

6. DECK IDENTITY PROFILES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

TREE DECK — "Harmony & Regrowth"
  
  Primary Tags: Nature (10), Knowledge (8), Land (8), Culture (6)
  Secondary: Spiritual (4), Amenity (3), Trophy (3)
  
  Signature Cards:
    • Pasture & Crags (×4 each) — anchor Land/Nature theme, support Nomad/Highlander
    • Highlander & Nomad (×3 each) — conditional domain placement (if Crags/Pasture)
    • Harvest (×4) — triggers Harvest event → Solstice/Kinship/Plough responses
    • Regrowth (×2) — dawn phase recovery (return Pastures)
  
  Triggers: Heavy on on_order (12 cards), on_dawn (6 cards), on_rite (2 cards)
    Actions: Positive/enabling (draw, place, scry, recover)
    Defenses: Eldership (Brawl cancel if shared culture)
  
  Identity Mechanics:
    1. CULTURE ALLIANCE: Shared culture = mutual support
       └─ Gathering brawls allies' domains
       └─ Solstice places Culture in allies' domains
       └─ Chiefdom moves allied mobs
       └─ Only Tree builds this, but Claw has Chiefdom
    
    2. LAND RECUPERATION: Pasture/Crags enable cards that return
       └─ Highlander moves to domain if Crags present
       └─ Nomad moves to domain if Pasture present
       └─ Regrowth recovers Pastures at dawn
       └─ Creates "refilling cycle"
    
    3. SPIRITUAL MAGIC: Rite event responses
       └─ Sky Dance (order) triggers Rite
       └─ Sacred Grove (order) scries for Spiritual or triggers Rite
       └─ Worship cards respond to Rite
    
    4. KNOWLEDGE RECOVERY: Recover cards from discard
       └─ Herbalism (order, cost: Knowledge/Nature) → recover from discard
       └─ Remembrance (order, count Knowledge) → recover 1-N from discard
       └─ Enables "grind it out" late-game strategy
    
    5. ZONE MANIPULATION:
       └─ Sowing (requires 2× Nature) → order Wheat zone
       └─ Withered Crop (requires Harvest in discard) → order Wheat zone
       └─ Forage (order, Presence in domain) → draw 3 from Tree, pick 1
       └─ Allows controlling card flow
  
  Win Condition: NATURE tags (if Tree depletes)
  
  Flavor: Regenerative, diplomatic, magical, knowledge-based
  Archetype: Support/control — helps allies, recovers resources, enables others

WHEAT DECK — "Labor & Community"
  
  Primary Tags: Labour (12), Amenity (6), Nature (3), Land (3)
  Secondary: Unit (2)
  Unique: Only deck with "Amenity" as primary identity
  
  Signature Cards:
    • Labour cards (Plough, Granary, Mill, Animal Husbandry, Apprenticeship, Irrigation)
      └─ Define Wheat's work ethic
      └─ Mix of order and harvest triggers
    
    • Amenity cards (Tavern, Well, Maypole)
      └─ Community comfort; facilitate other cards
      └─ Tavern returns Discontent (helps against Claw)
      └─ Well refills Season + Fields, allows dual ordering
    
    • Fields zone (×5 cards max) — unique to Wheat
      └─ Can be accessed by Wheat zone (pay Claw tax)
      └─ Can be accessed by Orchard (no tax!)
      └─ Compost exiles discard → refill Fields
  
  Triggers: Heavy on on_order (11 cards), some on_dawn (3 cards), on_harvest (1 card)
    Unique: on_rumour (Village Gossip) — only card responding to Rumour
    Actions: Resource generation (draw coin, feast, refill fields)
    Defenses: Militia (Brawl cancel), Tavern (Feast cleanup)
  
  Identity Mechanics:
    1. LABOUR PRODUCTION: Labour cards drive decision-making
       └─ Plough: order Wheat zone or trigger Feast
       └─ Granary: order Granary → Feast
       └─ Mill: discard Mill → draw Coin
       └─ Animal Husbandry: feast + draw Coin + optional Pasture sacrifice
       └─ Apprenticeship: order Coin zone if opponent has Craftsmanship
       └─ Irrigation: refill Fields at dawn
    
    2. AMENITY COMFORT: Community features
       └─ Tavern: Feast → return Discontent to pile (anti-Claw tech)
       └─ Well: order zone + refill Season/Fields (cooperative play)
       └─ Maypole: pure Amenity tag (no mechanics, pure identity)
    
    3. FIELD MANAGEMENT: Unique zone with special rules
       └─ Fields refill during Harvest event
       └─ Orchard picks without tax (incentivizes building Orchard)
       └─ Compost: exile discard → refill Fields → order Wheat zone
       └─ Creates "cycle" potential
    
    4. CROSS-DECK LINKAGE:
       └─ Sowing/Withered Crop (Tree) can order Wheat zone
       └─ Animal Husbandry + Plough can trigger Feast
       └─ Mill/Apprenticeship access Coin zone
       └─ Feed the Commoners: return Discontent to Claw pile
       └─ Militia: counters Claw's Brawl
    
  Win Condition: AMENITY tags (if Wheat or Coin depletes)
  Issue: Wheat and Coin share AMENITY as winning condition!
  
  Flavor: Grounded, communal, labor-intensive, anti-conflict
  Archetype: Ramp/grind — generates resources, survives conflict, enables others

CLAW DECK — "War & Discontent"
  
  Primary Tags: Discontent (36!), Mob (19), Unit (13), Trophy (4), Hunt (4)
  Secondary: Spiritual (3), Allegiance (2), Knowledge (1)
  **HEAVILY DISCONTENT-FOCUSED** (36 copies out of 52 = 69% have Discontent)
  
  Signature Cards:
    • Raid & Poach (×4 each) — core Brawl combat
      └─ Raid: Brawl defense (give/discard card to attacker)
      └─ Poach: triggers Feast, uses Hunt tag, limited by pastures
    
    • Discontent pool (Discontent-tagged cards)
      └─ Racketeering, Tyranny, Land Grab, Rite of Passage, Culling, Ingenuity,
         Uprising, Blood Feud, Enforcers
      └─ Can be returned to pile by: Plough, Tavern, Feed the Commoners
      └─ Returned Discontent → refill Claw pile (extends game!)
    
    • Mob cards (many) — military units
      └─ Warband, Raid, Scavenge, Poach, Marauders, Blood Feud, Enforcers
      └─ Incite moves mobs at dawn
      └─ Chiefdom moves allied/own mobs
  
  Triggers: Heavy on on_order (14 cards), on_dawn (4 cards), on_brawl (6 cards)
    Unique: Multi-trigger cards (e.g., Spoils of War on_dawn + on_brawl)
    Actions: Aggressive (draw, move cards, trigger events)
    Defenses: None explicit; instead, retaliatory effects
  
  Identity Mechanics:
    1. DISCONTENT GENERATION & RECYCLING:
       └─ 36 Discontent copies means constant flow of "chaos"

7. DESIGN PATTERNS & PRINCIPLES EXTRACTED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

┌─ COPY COUNT DISTRIBUTION ─────────────────────────────────────────────────────┐

Standard Distribution in Mature Decks (Tree, Claw, Wheat):
  • ×4 copies (2-3 cards): Flagship cards — core identity, game-defining
  • ×3 copies (2-4 cards): Strong supporting cards
  • ×2 copies (8-12 cards): Fillers and tactical options
  • ×1 copies (3-8 cards): Unique effects, high power level, situational

Pattern: ×4 cards are few but powerful (e.g., Harvest, Pasture, Crags)
Pattern: ×1 cards tend to be high-complexity (e.g., Sacred Grove, Dusk Rite)

Expected for Coin: 2-3 ×4 cards, 3-4 ×3 cards, 8-12 ×2 cards, 4-8 ×1 cards
                   Total: ~50 copies, ~20 unique cards

├─ TRIGGER ARCHITECTURE ───────────────────────────────────────────────────────┤

Ratio: on_order dominates (30 of 68 cards with triggers)
  Tree:   12 on_order, 6 on_dawn, 2 on_rite
  Claw:   14 on_order, 4 on_dawn, 6 on_brawl, 1 on_rite, 3 on_feast
  Wheat:  10 on_order, 3 on_dawn, 1 on_harvest, 2 on_feast, 1 on_rumour

Pattern: Most cards trigger on_order (player agency)
Pattern: Limited on_brawl responses (mostly Claw — 6 of 9 total)
Pattern: Very few on_feast/on_rumour (3 total on_feast, 1 on_rumour)

Architecture: Actions are triggered by ORDER, not by events
  • Events (Brawl, Rite, etc.) are SIDE EFFECTS of ordering
  • Cards can respond to those events secondarily
  • This creates: "order triggers event → side effects → responders"

For Coin Deck: Expect 12-15 on_order cards, few on_dawn, unique on_XXX triggers

├─ TAG DESIGN ──────────────────────────────────────────────────────────────────┤

Three categories of tags:

1. SLOT TAGS (mutually exclusive per player):
   • Culture — One per player
   • Allegiance — One per player  
   • Religion — One per player (unimplemented)
   Usage: Create player identity, enable/disable interactions

2. IDENTITY TAGS (deck signature):
   • Nature, Knowledge, Spiritual (Tree)
   • Discontent, Mob, Unit, Trophy, Hunt (Claw)
   • Labour, Amenity, Land (Wheat)
   Purpose: Define deck flavor, enable synergy, drive win condition

3. MECHANICAL TAGS (gates/costs):
   • Land (Land Grab, Sowing requirements)
   • Knowledge (Herbalism cost, Remembrance limit)
   • Nature (Sowing requirement)
   • Mob (Militia cost, Incite fuel)
   • Hunt (Poach limit)
   Purpose: Create decision points, synergy costs, balance

Pattern: Cards can have multiple tags (e.g., Raid = Unit + Mob + Discontent)
Pattern: Each deck has 3-4 signature tags covering ~60% of copies
Pattern: Mechanical tags overlap between decks (e.g., Land in both Tree & Wheat)

For Coin Deck: 
  • Signature tag: Craftsmanship (NEW, unique to Coin)
  • Secondary tags: Labour, Tool(?), maybe Prosperity(?), Trade(?)
  • Mechanical tags: Could enable/gate other cards' actions

├─ EVENT RESPONSE PATTERNS ─────────────────────────────────────────────────────┤

Brawl Event: Primarily Claw domain (6 of 9 Brawl responders from Claw)
  • Claw cards decide how to resolve: give card, cancel, retaliate
  • Non-Claw defenses are rare (Eldership, Militia, Crags from Tree/Wheat)
  • Pattern: Attacker triggers Brawl → defender responds with consequence

Rite Event: Shared between Tree, Claw, Candle (Worship cards)
  • Triggered by Tree (Sky Dance, Sacred Grove, Dusk Rite)
  • Also by Blood Offering, Gathering choice, Worship of War
  • Responders are mostly Worship cards (Tree + Claw + Candle)
  • Pattern: Any player with Spiritual cards can benefit

Harvest Event: Triggered by Tree cards, responded by all decks
  • Wheat Zone refills Fields automatically
  • Plough, Solstice, Kinship make decisions
  • Animal Husbandry can sacrifice
  • Pattern: Major resource generation moment

Feast Event: Lesser event, few responders
  • Triggered by Granary, Plough, Animal Husbandry, Poach, Marauders
  • Tavern (return Discontent), Marauders (draw), Share the Spoils (draw)
  • Pattern: Secondary mechanic, not central

Rumour Event: Only triggered by Coin Zone Trade
  • Only Village Gossip responds
  • Pattern: Narrow, specialized event

For Coin Deck: Could have unique on_rumour cards or other event responses
  • Option 1: Coin-specific event (like how Feast/Rite exist)
  • Option 2: Respond to existing events uniquely
  • Option 3: Trigger new event type from Coin ordering

├─ CROSS-DECK LINKAGE ──────────────────────────────────────────────────────────┤

How decks reference each other:

TREE → WHEAT:
  • Sowing (order): requires 2× Nature, orders Wheat zone
  • Withered Crop (order): requires Harvest in discard, orders Wheat zone
  • Regrowth (dawn): recovers Pastures for everyone (used by Wheat.AnimalHusbandry)

TREE → CLAW:
  • Crags (order): scouts Claw top 3, puts in discard
  • Eldership (brawl): cancels Brawl if shared culture with attacker

TREE → COIN:
  • Oral Tradition (order): requires coin card in domain, discards it, draws Candle

WHEAT → CLAW:
  • Wheat Zone (order): Claw tax = draw N from Claw
  • Tavern (feast): returns Discontent to Claw pile
  • Feed the Commoners (dawn): returns 0-3 Discontent to Claw pile
  • Plough (order): returns 1 Discontent to Claw pile
  • Militia (order/brawl): discards Mob cards

WHEAT → COIN:
  • Mill (order): discards Mill, draws Coin
  • Animal Husbandry (order): draws Coin (can trigger Feast that draws Coin)
  • Apprenticeship (order): orders Coin zone if opponent has Craftsmanship

CLAW → WHEAT:
  • (No explicit links; mobs can end up in Wheat domains)
  • Land Grab: takes Land from Season (seed from Wheat ordering)

CLAW → COIN:
  • (No explicit links)
  • Ingenuity (dawn): draws Coin

Pattern: Tree ← most connected (Sowing, Withered Crop access others)
         Wheat ← tax system with Claw, access to Coin and Tree
         Claw ← mostly standalone, imported Discontent creates synergy
         Coin ← minimal connections (mostly accessed by others)

For Coin Deck: Should have:
  • Access points (other decks ordering Coin zone)
  • Outward triggers (Coin cards triggering other zones)
  • Internal synergies (Coin cards with Coin cards)
  • Probably avoid heavy cross-deck referencing (Coin is new)

├─ IDENTITY & THEME ───────────────────────────────────────────────────────────┤

Coin's Role: Economic/crafting system
  • Not military (Claw)
  • Not agricultural (Wheat)
  • Not spiritual (Tree, Candle)
  • NOT amenity (that's Wheat's angle)

Proposed Theme: CRAFTSMANSHIP & INNOVATION
  • Artisans, tools, trade, innovation
  • Creating value through skill
  • Economic specialization

Primary Tags:
  1. CRAFTSMANSHIP (new, ~12 copies) — Coin's signature identity tag
     └─ Enables Apprenticeship (order Coin zone if opponent has this)
     └─ Used in win condition (if Coin depletes)
     └─ Flavor: Skill, expertise, mastery
  
  2. LABOUR (~8-10 copies already on Mine × 2, need 6-8 more)
     └─ Shared with Wheat (indicates cross-deck synergy)
     └─ Reinforces "work-based economy" angle
  
  3. TOOL (new, ~8 copies) — Physical manifestations of craftsmanship
     └─ Represents the output of Coin's work
     └─ Could enable other cards' effects
  
  4. TRADE (new, ~4-6 copies) — Economic exchanges
     └─ Synergy with Coin Zone's trade mechanic
     └─ Could be triggered by trading in Coin zone
     └─ Creates feedback loop

Secondary Tags:
  • PROSPERITY — wealth accumulation
  • INNOVATION — new technologies
  • KNOWLEDGE — learning from Wheat/Tree
  • (Avoid AMENITY — that's Wheat's win condition!)

├─ CARD ARCHETYPES ────────────────────────────────────────────────────────────┤

FOUNDATION CARDS (×4, 2-3 cards):
  Example: Mine (already ×2)
  • Simple, strong, repeatable
  • Define Coin's basic competency
  • Could be: Forge, Smithy, Marketplace

PRODUCER CARDS (×3, 3-4 cards):
  • Generate resources (draw Coin, access Wares)
  • Have on_order mostly
  • Example archetypes:
    - Artisan (×3): creates Craftsmanship cards (on_order effect)
    - Apprentice (×3): learns from others (on_order, cross-deck reference)
    - Workshop (×3): builds Tools (on_order, creates Tool cards)

SYNERGY CARDS (×2, 8-12 cards):
  • Fuel each other
  • Enable other decks' cards
  • Mix of on_order, on_dawn, on_trade(?)
  • Examples:
    - Trade Good (×2): enables trades
    - Innovation (×2): triggers on craftsmanship count
    - Prosperity (×2): wealth generation
    - Tool (×2): output of craftsmanship

UNIQUE CARDS (×1, 4-8 cards):
  • High complexity or power
  • Advanced synergies
  • Examples:
    - Grand Master (×1): powerful craftsperson, complex on_order
    - Invention (×1): creates temporary bonus
    - Economic Treaty (×1): enables Apprenticeship cross-deck
    - Resource Optimization (×1): converts resources

EVENT-RESPONSE CARDS:
  • Should respond to TRADE (primary) or RUMOUR (secondary)
  • Could respond to HARVEST (cross-deck synergy)
  • Should NOT respond to BRAWL/RITE (too chaotic for economic deck)

├─ MECHANICAL PRINCIPLES ──────────────────────────────────────────────────────┤

1. COIN ZONE ACCESS ROUTES:
   Existing:
   • Mill: discard Mill → draw Coin
   • Animal Husbandry: (feast) draw Coin
   • Apprenticeship: order Coin zone if opponent has Craftsmanship

   New Cards Should:
   • Provide more access points (via Coin cards' on_order)
   • Incentivize building Craftsmanship (for Apprenticeship)
   • Work with Wares (Coin Zone's face-up area)

2. WARES SYSTEM:
   Coin Zone mechanics:
   • BUY: pick Ware from Wares (no cost, just presence)
   • TRADE: put domain card in Wares, draw from Coin pile, trigger Rumour

   For Coin Cards:
   • Could trigger when cards enter Wares
   • Could benefit from buying from Wares
   • Could synergize with Rumour event

3. CRAFTSMANSHIP-SPECIFIC MECHANICS:
   • Count Craftsmanship tags (like how Tree counts Nature, etc.)
   • Cost Craftsmanship (pay with Craftsmanship cards to order)
   • Sacrifice Craftsmanship (discard to fuel effects)
   • Enable others (Apprenticeship, other Coin cards)

4. CROSS-DECK IMPACT:
   • Should enable Wheat's Apprenticeship (anti-hoarding Craftsmanship)
   • Should benefit from being traded into Wares (Rumour event)
   • Could provide "tax alternative" (if something gets too strong)
   • Should NOT create feedback loops that break Claw/Tree

5. RISK/REWARD:
   • Craftsmanship should be valuable (enable multiple effects)
   • But building it should have costs (opportunity cost, complexity)
   • Should incentivize playing Coin cards over just accessing them from elsewhere

  • on_trade: 2-4 cards (NEW event type OR respond to Coin Zone trade)

  • Light on_dawn (cleanup phase)

  • Selective on_rumour (specialized)
  • No combat/spiritual triggers (not Coin's identity)
